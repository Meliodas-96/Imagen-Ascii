# Conversor de Imagen a ASCII

Este script de Python convierte imágenes en arte ASCII utilizando una interfaz gráfica creada con Tkinter.

## Descripción

El script permite seleccionar una imagen, convertirla a una representación en ASCII y guardar el resultado en un archivo de texto. Utiliza la biblioteca PIL para manipular imágenes y Tkinter para la interfaz de usuario.

## Características

- Conversión de imágenes a arte ASCII.
- Interfaz gráfica para facilitar la selección de archivos y la visualización del resultado.
- Posibilidad de guardar el arte ASCII en un archivo de texto.

## Requisitos

- Python 3.x
- Bibliotecas: `tkinter`, `PIL` (Pillow)

## Instalación

1. Clona este repositorio o descarga el archivo `Imagen en ASCII.py`.

2. Instala las dependencias necesarias ejecutando:

3. pip install pillow
